# Share this curriculum on GitHub

## Instructions

1. Create a GitHub repository named cybersecurity-web-learning or another descriptive name. Choose private if you want to share it only with your cousin; choose public if you want anyone to read it.
2. Add this folder’s Markdown documents and lessons directory, preserving the folder structure. GitHub’s upload interface or GitHub Desktop can do this without command-line instructions.
3. Open the README on GitHub and follow several relative links to confirm the lessons are in the right locations.
4. For a private repository, invite your cousin through the repository’s collaborator settings. For a public repository, send its URL.
5. Have her create a separate incident-tracker-app implementation repository. The curriculum remains a reference containing instructions, prompts, and resource links only.

Publishing the curriculum is different from hosting the application she will build. Application deployment comes in lesson 17. Never upload local credential files, generated dependencies, or private incident data with either repository.
