# 05 — Learn programming with incident data

## Before you start

Complete lesson 04.

## What you will learn

Learn variables, values, types, comparisons, conditionals, loops, functions, parameters, return values, and scope.

## Instructions

1. Describe an incident using plain language: a title, severity, and status. Identify the kind of value each field needs.
2. Write a small function yourself that decides whether a severity is allowed. Separate returning an answer from displaying it.
3. Practice conditionals using the three allowed statuses. Predict what happens for an unexpected status before running the program.
4. Use a loop to inspect several fictional reports. Explain how the loop finishes.
5. Trigger and read a harmless error. Find its file and line in developer tools, fix the cause, and record the lesson.

## Done when

- [ ] Explain a parameter versus a return value.
- [ ] Predict the result of a small conditional before running it.
- [ ] Handle invalid input intentionally instead of relying only on a happy path.
