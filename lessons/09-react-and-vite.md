# 09 — Start the React version

[Previous lesson](08-http-and-async.md) · [Course home](../README.md) · [Next lesson](10-react-components-and-props.md)

## Before you start

Complete lessons 00–08 conceptually; finish the local request exercise once the server works.

## What you will learn

Understand Node.js, npm, dependencies, a development server, JSX, components, and the difference between development and production builds.

## Instructions

1. Read Vite’s current prerequisites and install a compatible supported Node.js LTS release. Use the official setup guide rather than old commands from memory.
2. In your implementation repository, preserve the plain HTML prototype in a clearly named practice folder. Create a separate React application using Vite’s React JavaScript template.
3. Read the generated files and explain the package manifest, lockfile, source folder, entry point, and public assets. Do not add TypeScript or a CSS framework yet.
4. Run the development server following Vite’s instructions. Replace the starter screen yourself with a simple tracker heading and your existing CSS.
5. Build and preview the app locally using the documented workflow. Compare the source files with the generated output, then finish lesson 08’s request exercise.

## Done when

- [ ] The React app runs locally and its production build succeeds.
- [ ] Explain JSX versus HTML and Node.js versus browser JavaScript.
- [ ] Identify which files are your source and which are generated dependencies or build output.
