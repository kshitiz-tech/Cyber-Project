# 01 — Build the first page with HTML

[Previous lesson](00-setup-and-git.md) · [Course home](../README.md) · [Next lesson](02-html-forms.md)

## Before you start

Complete lesson 00.

## What you will learn

Learn elements, attributes, document structure, headings, paragraphs, lists, links, and semantic page regions.

## Instructions

1. Sketch a dashboard on paper with a header, navigation, main content, incident list, and footer.
2. Create the first HTML page yourself in the implementation repository. Add a descriptive browser title, page language, one main heading, and logical subheadings.
3. Write three fictional incident summaries using the project brief. Use meaningful structure before styling anything.
4. Add navigation links and a separate report page. Use links for navigation and buttons for actions.
5. Inspect the document in developer tools and explain how the browser represents the elements.

## Done when

- [ ] The page makes sense with no CSS.
- [ ] Navigation links reach the intended page.
- [ ] Heading levels describe the content hierarchy; they are not chosen for text size.

## ChatGPT prompt — guided practice

> Teach me semantic HTML by helping me plan my incident tracker dashboard. Explain elements and attributes using plain language, then ask me to choose suitable page regions. Give me a small writing task and wait for my attempt. Do not provide markup or a finished page.

## ChatGPT prompt — review my attempt

> Review the HTML I paste for structure, heading order, and link versus button choices. Describe the three most useful fixes without rewriting my work. I will share only fictional data and remove credentials before sharing my work.
