# 00 — Set up your learning workspace

[Roadmap](../ROADMAP.md) · [Course home](../README.md) · [Next lesson](01-html-foundations.md)

## Before you start

No programming experience required. Read the project brief first.

## What you will learn

Understand files, folders, a browser, an editor, a terminal, and version history before installing an application framework.

## Instructions

1. Create a separate implementation repository named incident-tracker-app. Keep this curriculum repository as your reference; write your application in the new repository.
2. Install a code editor and use its file explorer to create a practice folder. Learn how extensions differ from file names and how to locate a saved file.
3. Use GitHub Desktop or the GitHub website to make a first documentation commit, a small branch change, and a pull request. Explain the difference between saving, committing, and pushing.
4. Open browser developer tools. Find the Elements, Console, Network, and Application or Storage panels. Record what each helps inspect.
5. Write three learning goals. Save screenshots and reflections in your own learning journal. Node.js installation comes in lesson 09; HTML and CSS practice does not require it.

## Done when

- [ ] Find a file you saved and explain its location.
- [ ] Explain repository, commit, branch, and pull request in your own words.
- [ ] Open developer tools without help and identify the Console panel.

## ChatGPT prompt — guided practice

> Help me set up a beginner web-development workspace for an incident tracker. First ask my operating system and whether I prefer GitHub Desktop or the website. Guide me through one small action at a time; explain any command before suggesting I run it. Do not write application code.

## ChatGPT prompt — review my attempt

> Ask me to explain saving versus committing versus pushing, then help me investigate one setup problem using its exact error message. I will share only fictional data and remove credentials before sharing my work.
