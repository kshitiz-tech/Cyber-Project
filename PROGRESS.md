# Progress journal

## Instructions

Copy this template into your implementation repository’s own notes. Create an entry after each lesson and update the roadmap checkbox only when you can demonstrate the completion checks. Do not record passwords, tokens, or real incident details.

For each entry, record:

- Lesson number and date.
- What I built or practiced.
- One concept explained in my own words.
- Expected behavior and the observed result of each completion check.
- One bug, its cause, and how I verified the fix.
- The most useful resource link and section.
- What help I requested from ChatGPT and what I verified independently.
- One question I still have.
- A screenshot, test result, or commit link that demonstrates progress.
- My next small task.

## Weekly reflection

Explain one feature without opening its source. Rebuild one small behavior from memory. Compare this week’s work to last week’s and identify a specific skill that improved. If you are stuck, reduce the next task until its expected outcome is easy to describe.

## ChatGPT prompt

> Help me reflect on my learning journal. Ask me which result I can demonstrate, which concept I can explain independently, and which part still depends on hints. Suggest one focused practice task for my weakest area. Offer a worked example or help implement a practice task if useful, but do not fill in evidence I have not provided.
