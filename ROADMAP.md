# Roadmap

## Instructions

Work in order and use each lesson’s completion checks as the gate to the next one. Spend a session reading, a session implementing, and a session checking or explaining if that pace helps. Estimates are planning aids, not deadlines.

| Suggested period | Focus | Checkpoint |
| --- | --- | --- |
| Weeks 1–2 | Lessons 00–04 | Explain and navigate your own accessible HTML/CSS pages |
| Weeks 3–4 | Lessons 05–08 | Explain functions, collections, events, and HTTP |
| Weeks 5–8 | Lessons 09–14 | Build the React tracker with ChatGPT’s help and explain how it works |
| Weeks 9–10 | Lessons 15–17 | Demonstrate tests, limitations, and a hosted frontend |
| Extra practice | Repeat difficult exercises | Rebuild one small feature from a blank file |
| Optional later phase | Lessons 18–21 | Prove server-side permissions with two users |

The local HTTP exercise in lesson 08 can be completed after lesson 09 starts the Vite server. This is the only planned deferred exercise; do not skip its concepts.

## Milestone review instructions

At each checkpoint, demonstrate the feature, explain a design decision, show one failed test or bug you corrected, and describe one limitation. If you cannot explain the implementation, return to a smaller exercise before adding another dependency.
