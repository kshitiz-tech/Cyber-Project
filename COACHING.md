# Build and learn with ChatGPT

ChatGPT can be your tutor and coding partner throughout this project. Ask for explanations, examples, working implementations, complete small files, setup commands, tests, and debugging help. You do not need to solve a task alone before asking for help. This guide contains prompts only; put the code ChatGPT helps you create in your implementation repository.

## Instructions

1. Open the current lesson and paste its guided-practice prompt into ChatGPT. Include the lesson’s instructions and completion checks so the chat has enough context.
2. Describe your setup and what you have built, or say that you are starting from scratch. Share relevant file contents and versions when needed.
3. Ask ChatGPT to help implement one feature at a time. Request exact file paths, code or complete small files, and an explanation of unfamiliar syntax.
4. Run the result locally. Share the exact error or observed behavior so ChatGPT can help diagnose and fix it.
5. Ask why the solution works, change something small, and run the lesson’s checks. Use the linked official documentation to verify unfamiliar advice.
6. Record what you learned and commit the working milestone. Ask for another explanation or worked example whenever you need one.

Use fictional incident data and remove passwords, tokens, and session cookies before sharing files. Treat generated code as something to run, inspect, and test; a suggested solution is not proof that a feature works.

## ChatGPT prompt — understand a concept

> Explain the concept in my current lesson in beginner-friendly language. Show a small working code example related to my incident tracker, explain it line by line, and tell me where and how to run it. Help me adapt it to my app. Then ask one understanding question and suggest one small change I can try. Use the lesson’s official resource links.

## ChatGPT prompt — build a feature together

> Help me implement the feature described in this lesson. Ask for my current project structure and relevant files, or help me start if I have none. Break the feature into manageable steps. Provide the code, commands, and complete small files I need, identify exact file paths, and explain why each change is necessary. Keep the implementation appropriate to my current lesson and installed versions. Give a run or test check after each step and help me fix any errors before continuing.

## ChatGPT prompt — debug my attempt

> Help me fix this problem. Ask for the expected behavior, observed behavior, exact error text, relevant versions, and the smallest relevant excerpt. Explain the likely cause, give a targeted correction or revised file, and tell me how to verify the fix. If the evidence is incomplete, ask for a specific diagnostic check instead of guessing. Explain what I should learn from the bug.

## ChatGPT prompt — review my attempt

> Review my work against the lesson’s completion checks. Prioritize correctness, readability, accessibility, and security where relevant. Explain the most important improvements and provide corrected code or revised files when useful. Tell me how to test each change and distinguish your review from checks I still need to run locally. Help me understand the result rather than only handing me a replacement.

## ChatGPT prompt — check my understanding

> Ask me five questions about this lesson, one at a time. Include a prediction question, an edge case, and a design choice. If I struggle, explain the answer with a worked code example and let me try a similar question. End with a small modification to my app; offer hints or a complete explained solution if I need help.
